# Grocery Product Guide

This is a reference for matching a pasted shopping list (e.g. from the shared Alexa list) to the family's actual preferred brand/product — not a list of things to add automatically. Nothing here gets added to a cart unless it's on the list the user pastes in, or they ask for it directly. Edit this file as preferences change or new shorthand needs mapping — the skill reads it fresh each time, so there's no need to report updates separately.

Built from an analysis of 23 past Instacart "family order" receipts (Dec 2025–Jul 2026): 21 from DeCicco & Sons (Katonah) and 2 from Stop & Shop (Lavallette), plus corrections from actual use. Frequency notes are informational (how established a habit is), not a rule for what to add.

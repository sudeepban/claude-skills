# Meal Options

Edit this list as your family's go-to meals change. The skill reads this file fresh each time it plans a week — no need to tell it about updates separately.

## Home-cooked

One combined list, each meal tagged with a complexity/cost point value (1 = quick and cheap, 5 = involved and pricier). Use the points to match meals to how busy the week is — low points for heavy weeks, high points for light weeks — rather than picking from separate "simple" and "complex" buckets.

Point values below are a starting proposal — adjust them freely as you find they don't match reality.

| Meal | Points |
|---|---|

| Quesadillas | 1 |
